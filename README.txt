AHMED OSAMA KAMAL — PORTFOLIO WEBSITE

Files:

- styles.css: responsive dark navy / blue visual design
- script.js: mobile navigation, reveal effects and current footer year
- assets/Ahmed-Osama-Kamal-CV.pdf: CV download linked from the website

Preview locally:
1. Keep the folder structure unchanged.
2. Open index.html in a modern browser.

Free publishing option — GitHub Pages:
1. Create or sign in to a GitHub account.
2. Create a public repository (for example: ahmed-osama-portfolio).
3. Upload all files and folders in this package, keeping the assets folder.
4. In repository Settings > Pages, choose Deploy from a branch.
5. Select the main branch and root folder, then Save.
6. GitHub will publish the site at the repository's Pages URL.

Before publishing, review all contact details, project descriptions, dates and certification names. The text is based on the supplied CV; add project screenshots or architecture diagrams only if you have permission to share them publicly.
